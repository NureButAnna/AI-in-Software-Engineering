# PaperTrail — вимоги, контракт даних, архітектура та API
 
Лабораторна робота №1 з дисципліни «Штучний інтелект у програмній інженерії».
Група **ПЗПІ-23-8**.
 
**PaperTrail** — система організації документів, заяв і дедлайнів. Вона зберігає документи з терміном дії, веде справи зі статусами, задачами та чек-листами, надсилає нагадування і показує на дашборді прострочені та найближчі справи.
 
Мета роботи — перетворити специфікацію й рішення замовника на перевірювану проєктну документацію:
аналіз вимог → user stories → контракт даних → перехресна перевірка → архітектура → API → простежуваність.
Кожне правило має бути пов'язане з вимогою, а пропозиції AI — перевірені людиною, виправлені чи відхилені й задокументовані.

## Межі результату
 
Результат роботи — проєктна документація, **не реалізований застосунок**.
На цьому етапі не доведено:
 
- роботу API: відповіді в `api-contract.md` є проєктними прикладами, а не результатами запущеного сервера;
- детальний API для задач, документів, файлів, установ і нагадувань — для них є лише попередні маршрути;
- погодження шести `[ПРИПУЩЕНЬ]`, обраних під час рев'ю, та відкритих питань OPEN-C05 – OPEN-C07;
- виконання тестів: у `traceability.csv` названо майбутні тести.
