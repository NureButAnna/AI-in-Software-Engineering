# Лабораторна робота № 3 — PaperTrail

Тестування контракту, контрольовані дефекти й перевірка виправлень.

| Шлях | Вміст |
|---|---|
| `app/` | Перевірена реалізація PaperTrail для ЛР3 |
| `tests/` | Повний набір T1: успадковані тести й доповнення ЛР3 |
| [`docs/`](docs/) | Звіт, AI-журнал і матриця простежуваності |
| [`reports/lr3/`](reports/lr3/) | Логи, покриття, Bandit, матриця мутацій і патчі |
| `experiment/` | Контрольні запити ЛР3 і допоміжний модуль для успадкованих тестів |

## Перевірка

З кореня репозиторію:

```sh
cd lab3
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
python -m pytest -q
python -m ruff check app tests --select E4,E7,E9,F,I
```

Почніть зі [звіту ЛР3](docs/lab-03.md). [Сценарій захисту](docs/defense.md) розподіляє демонстрацію між п’ятьма учасниками. [Інструкція до експерименту](reports/lr3/README.md) описує відтворення оригінальних прогонів на зафіксованих комітах.
